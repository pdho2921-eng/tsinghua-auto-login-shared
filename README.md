# 清华网站自动重登 · 共享试用版

在网络学堂、信息门户（含校外 WEBVPN）和学生邮箱登录失效后，在原标签页自动重新登录。首次保存账号密码后，日常无需手动启动本机助手。

## 选择安装包

| 系统 | 安装包 | 使用说明 | 验证状态 |
| --- | --- | --- | --- |
| Mac | `dist/tsinghua-auto-login-shared-macos.zip` | [Mac 使用说明](docs/MACOS.md) | 本机安装闭环与浏览器回归通过；Intel、旧版系统、Mac Edge 待实测 |
| Windows 11 x64 | `dist/tsinghua-auto-login-shared-windows-x64-test.zip` | [Windows 使用与测试说明](docs/WINDOWS.md) | 已生成测试包；真实 Windows 与 Edge 验收待同学完成 |

两份压缩包分别包含本系统适用的程序、安装卸载入口和使用说明，不包含开发文件或另一系统的安装文件。校验值在 `dist/SHA256SUMS.txt`。旧传输光盘和解压目录已移出 `dist`，避免转交错包。

扩展版本 **0.1.6**，Mac 助手 **0.1.3**，Windows 助手 **0.1.0**，通信协议 **1**。扩展与助手版本不同是正常的。

## 使用方式

总开关与三个网站开关控制自动模式。左键工具栏图标在当前标签页手动重登，右键“选项”返回设置；设置页和不支持的网站不会被工具栏点击带走。WEBVPN 共用信息门户开关与清华账号。

邮箱未单独保存凭据时使用清华账号，单独保存后优先使用邮箱凭据，删除后恢复回退。主动编辑登录框时暂停自动处理；收到验证码、二次验证或学校拒绝后停止，不循环提交密码。

密码在本机由系统保存：Mac 使用登录钥匙串，Windows 使用当前用户 DPAPI 加密。保存后清空密码框；复制和眼睛按钮只处理当前输入，不读取已保存密码。各系统的隐私说明随对应安装包提供。
