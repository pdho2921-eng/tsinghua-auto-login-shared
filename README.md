# 清华网站自动重登 · 共享试用版

在网络学堂、信息门户和学生邮箱登录失效后，自动重新登录并留在原标签页。首次保存账号密码后，日常无需手动启动本机助手。

当前面向 **macOS 11 及以上＋Chrome 106 及以上**构建，安装包同时包含 Apple 芯片和 Intel 的程序。Intel、旧版 macOS 和 Edge 尚待实机验收；Windows 暂未实现。

## 安装与首次设置

1. 解压完整的 `tsinghua-auto-login-shared-macos.zip`，双击其中的 `安装.command`。无需安装 KeePassXC、开发工具或自行编译。安装窗口会显示结果，并打开使用说明及扩展所在文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，进入扩展程序管理界面。在右上角选择开启“开发者模式”，然后点击“加载已解压的扩展程序”。选择安装后打开的 `extension` 文件夹。它位于 `~/Library/Application Support/TsinghuaAutoLoginShared/extension`；选择窗口中可按 Command＋Shift＋G 粘贴此路径。
3. 扩展设置页会自动打开。点击“检查连接”，保存清华账号和密码。未单独保存邮箱账号密码时，使用清华账号和密码；邮箱凭据不同时，再单独保存。
4. 保持“自动处理登录失效”开启，打开或刷新对应学校网站。如果原个人版也在使用，请先在 Chrome 扩展管理页关闭个人版，避免同时操作。

填写框旁的复制图标可将另一组对应框的内容填入当前框；另一组为空时不可用。密码框中的眼睛图标只显示当前输入的内容。保存后密码框清空，复制和显示按钮不会读取钥匙串中的密码。完成账号保存后，可关闭当前标签页。助手会按当前设置运行。

这是尚未正式签名、公证及上架的试用包。从网络下载后，macOS 可能要求在“系统设置 → 隐私与安全性”中确认打开安装文件或助手。如果学校管理的电脑不允许打开，请停止安装并反馈提示。安装流程不会关闭系统安全检查。

## 日常使用

打开支持的网站即可。点击工具栏图标，可在当前标签页手动执行登录；右键图标选择“选项”可返回设置页。主动退出某个网站后，助手会暂停该网站，直到再次点击图标。也可在设置页关闭“自动处理登录失效”，或在“各网站自动登录”中分别关闭网络学堂、信息门户、学生邮箱；关闭后仍可点击工具栏图标手动执行登录。总开关关闭时，三个网站均不自动登录；重新开启总开关会保留各网站的选择。设置页点击工具栏图标不会跳转。

邮箱单独保存后优先使用邮箱凭据，删除后恢复使用清华账号。

0.1.2 会等待页面加载、统一认证的异步初始化及登录按钮处理程序就绪后再提交。每个流程仍只提交一次；切到后台的成功页面也会确认完成，避免阻塞其他标签页。

登录时统一使用已保存的整组账号和密码，替换网页预填内容；数字学号与账号别名不必相同。检测到你主动编辑登录信息时，自动登录会暂停。网页错误提示中的“打开设置”可进入设置页，“关闭提示”仅隐藏提示，不会重新开始登录。

遇到密码错误、验证码或学校额外验证时，助手会停止，交由你处理。修改密码后，请在扩展设置页重新保存。网页本身需要的网络连接、额外验证不由助手代替。

## 更新与卸载

更新到 0.1.2：本次修复位于浏览器扩展，已安装的 0.1.0／0.1.1 助手可继续使用。将新版包中的 `extension` 文件夹替换到 Chrome 当前加载的扩展位置，在扩展管理页点击共享版的重新加载，并刷新学校网页。通过安装器安装时，该位置为 `~/Library/Application Support/TsinghuaAutoLoginShared/extension`；可在扩展详情页的“加载来源”核对。无需重新保存密码。

全新安装或需要更新本机助手时，运行试用包的 `安装.command`。本地试用签名更新后，系统可能要求重新授权；必要时在设置页重新保存密码。

卸载：如需删除密码，先在设置页点击对应账号的“删除已保存密码”；再运行 `卸载.command`，最后在 Chrome 中移除扩展。只移除助手会保留钥匙串中的密码，便于重新安装。也可在“钥匙串访问”中搜索“清华共享助手”后自行删除。

## 连接问题

先点击“检查连接”。显示未连接时，重新运行完整试用包中的安装文件。显示钥匙串锁定时，在“钥匙串访问”中解锁登录钥匙串，再重试。

连接处显示的是本机助手版本，设置页底部显示的是扩展版本。本次界面更新可继续使用 0.1.0 助手，两个版本号不同是正常的，不必因此重装。

## 查看错误提示

双击试用包内的 [错误提示预览](extension/preview.html)，即可切换 24 种提示，检查大小、颜色和文字。预览与实际网页共用提示样式，不会登录学校网站或读取账号密码。“关闭提示”可隐藏卡片，“重新显示”可恢复。以本地文件打开时，“打开设置”仅演示按钮反馈；在扩展内打开时会进入真实设置页。

本项目仅在本机处理凭据，没有账号服务器或遥测。详见 [隐私说明](PRIVACY.md)。开发和验收记录见 [开发说明](docs/DEVELOPMENT.md)。

虚拟机复测：旧 ISO 不会随 ZIP 自动更新。请使用当前 ZIP 重新生成传输光盘；更新后在扩展详情或设置页确认版本为 0.1.2，再分别检查单标签页和多标签页登录。
