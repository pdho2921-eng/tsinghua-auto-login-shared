# 清华网站自动重登 · Mac 试用版

本包仅供 macOS 使用，面向 macOS 11 及以上、Chrome 106 及以上。包含 Apple 芯片和 Intel 两种架构；Intel、旧版 macOS 和 Mac Edge 仍待实机验收。

扩展版本 0.1.6，Mac 助手版本 0.1.3。两个版本号不同是正常的。本次主要按平台整理安装包，共用的网站登录规则保持不变。

## 首次安装

1. 解压完整压缩包，双击 `安装.command`。无需安装开发工具或自行编译。
2. 安装完成后，按自动打开的“开始使用”说明，在 Chrome 地址栏输入 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择安装后打开的 `extension` 文件夹。
3. 设置页点击“检查连接”，保存清华账号密码。未单独保存邮箱凭据时，邮箱使用清华账号密码。

扩展位置为 `~/Library/Application Support/TsinghuaAutoLoginShared/extension`。文件选择窗口中可按 Command＋Shift＋G 粘贴路径。

这是尚未正式签名、公证及上架的试用包。macOS 可能要求在“系统设置 → 隐私与安全性”中确认打开；若学校管理策略不允许，请停止并反馈。安装流程不会关闭系统安全检查。

## 日常使用

助手由浏览器按需启动，无需手动打开。支持网络学堂、信息门户（含 WEBVPN）和学生邮箱。总开关与三个网站开关控制自动模式；左键工具栏图标在当前标签页手动重登，右键“选项”返回设置。

主动编辑登录框时暂停自动处理；遇到密码错误、验证码或额外验证时停止，由你继续完成。复制和眼睛按钮只处理当前输入，保存后密码框清空。

## 更新与卸载

更新时解压新包，运行其中的 `安装.command`，然后在 Chrome 扩展管理页重新加载共享版扩展。安装器会核对同批文件；失败时恢复旧安装。更新保留密码和自动登录开关。

如需删除密码，先在设置页点击对应账号的“删除已保存密码”；再运行 `卸载.command`，最后在浏览器中移除扩展。卸载默认保留登录钥匙串中的凭据。也可在“钥匙串访问”搜索“清华共享助手”后自行删除。

连接失败时先重新运行完整包中的安装文件。钥匙串锁定时先解锁登录钥匙串；更新后授权失效时可重新保存密码。

本项目没有账号服务器或遥测，详情见 `PRIVACY.md`。`extension/preview.html` 可预览错误提示，不读取账号密码。
