# 清华网站自动重登 · Mac 试用版

本安装包供 macOS 使用，面向 macOS 11 及以上、Chrome 106 及以上。包含 Apple 芯片和 Intel 两种架构，但 Intel、旧版 macOS 和 Mac Edge 均缺少实机验收。

发布整理版 **v0.1.9-preview.1**。扩展版本 **0.1.8**，Mac 助手版本 **0.1.4**。

## 首次安装

1. 解压完整压缩包，双击 `安装.command`。
2. 安装完成后，按自动打开的“开始使用”说明，在 Chrome 地址栏输入 `chrome://extensions/` 或手动打开插件管理，在右上角开启“开发者模式”，点击“加载未打包的扩展程序”，选择安装后打开的 `extension` 文件夹。
3. 设置页首次检查连接成功时自动显示“连接成功”，也可以手动点击“检查连接”运行检查，出现问题时打开下方折叠的“尚未安装或连接失败”排查。保存清华账号和邮箱的账户密码，可省略邮箱凭据填写并使用清华账号密码登录邮箱。

扩展位置为 `~/Library/Application Support/TsinghuaAutoLoginShared/extension`，可以在“加载未打包的扩展程序”的文件选择窗口中按 Command＋Shift＋G 粘贴路径。

这是尚未正式签名、公证及上架的试用包。macOS 可能要求在“系统设置 → 隐私与安全性”中授权。安装流程不会关闭系统安全检查。

## 日常使用

助手由浏览器按需启动，无需手动打开。支持网络学堂、信息门户（含 WEBVPN）和学生邮箱。插件适用范围由页面最下方的总开关与三个网站开关控制，默认均开启，可自行选择打开哪些网站的自动重连。日常使用时，在支持网站中左键工具栏图标在当前标签页手动激活重登，右键图标选择“选项”可返回设置页。

设置页的三个“打开网站”链接会新开标签页并启动一次登录，即使自动模式关闭，也允许这一次主动操作。系统要求手机二次验证后停止，不会循环提交。

主动编辑登录框时会暂停自动处理，遇到密码错误、验证码或额外验证时停止也会在右下角弹窗说明。

## 更新与卸载

更新时解压新包，运行其中的 `安装.command`。程序可以识别已有安装并覆盖更新，无需先卸载。随后在 Chrome 扩展管理页重新加载共享版扩展，刷新原先打开的学校网站即可启用新版。新版安装失败时会尝试恢复旧安装，恢复未完成时会提示备份路径。更新保留密码和自动登录开关。

如需卸载，先打开设置页，点击对应账号的“删除已保存密码”删除保存的密码。然后运行安装包内置的 `卸载.command`，最后在浏览器中移除扩展。只运行卸载会继续保留登录钥匙串中的凭据，可以在“钥匙串访问”搜索“清华共享助手”自行删除。

本项目没有账号服务器或遥测，详情见 `PRIVACY.md`。
