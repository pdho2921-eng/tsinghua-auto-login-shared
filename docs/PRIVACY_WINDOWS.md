# Windows 隐私说明

本项目在本机保存网络学堂、信息门户（含校外 WEBVPN）和学生邮箱的账号密码，用于这些网站的自动重登。

账号密码由 Windows 当前用户范围的 DPAPI 加密，分别保存到 `%LOCALAPPDATA%\TsinghuaAutoLoginShared.Credentials.v1` 中的固定文件。目录仅授予当前用户与系统账户访问。重装系统、更换 Windows 账号或迁移电脑后，可能需要重新保存密码。普通浏览器设置只保存账号名称、启停状态和重试限制；密码不写入浏览器设置、同步存储或日志。读取密码时，本机助手、扩展后台和对应登录页的扩展脚本会短暂处理密码，再填写到学校网页原有表单。JavaScript 运行时无法保证内存副本被立即物理擦除。

本项目不设服务器，不收集使用统计，不把账号密码发送给开发者。登录提交到学校网页自己的身份认证或学生邮箱地址。WEBVPN 共用“信息门户”开关与清华账号，密码仍只填入 `id.tsinghua.edu.cn` 的受认可认证表单；WEBVPN 资源站点与代理门户只识别状态和登录入口，不向其代理的其他网站填写密码。未单独保存邮箱凭据时，邮箱登录使用已保存的清华账号和密码；单独保存后优先使用邮箱凭据。

助手仅接受固定共享版扩展的浏览器连接，且只提供两类凭据的保存、读取、删除和状态查询。它不会接受任意文件路径、命令或其他凭据名称。浏览器后台会核对实际标签页、顶层文档、认证应用与表单目的地。该限制不等同于隔离已取得当前系统用户权限的其他本地程序。

登录当前 Windows 账号后可自动使用凭据，不要求每次读取均进行 Windows Hello 验证。系统加密不隔离已经取得当前 Windows 用户权限的其他程序。助手中的托管字符串无法保证内存副本被立即物理擦除。需要停止自动处理时，可关闭自动模式或指定网站的开关；需要停止凭据的自动读取时，可以删除已保存密码。主动点击工具栏图标或设置页网站链接仍可启动一次手动登录，关闭自动模式不会禁止这类主动操作。

在设置页可以分别删除两类凭据。删除单独保存的邮箱凭据后，邮箱恢复使用清华账号；若只想停止邮箱自动登录，请关闭该网站的开关。卸载助手默认保留凭据，并在卸载前明确提示删除入口。共享版使用独立的存储位置，不迁移或读取个人版 KeePassXC 密码库。
