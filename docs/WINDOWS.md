# 清华网站自动重登 · Windows 试用版

本包面向 **Windows 11、Intel／AMD 64 位电脑、Microsoft Edge**。这是等待 Windows 实机验收的测试包；生成安装程序、通过模拟检查，不等于已经确认 Edge 兼容。

扩展版本 **0.1.9**，Windows 助手版本 **0.1.2**。两者版本号不同是正常的。本次修复旧安装目录不能移动时的覆盖更新。此前的 0.1.8 诊断包只补充错误信息，请改用本包。Mac 也已同步登录启动功能，仍使用独立安装包。

## 首次安装

1. 解压完整压缩包，双击 **安装.exe**。直接以当前 Windows 用户运行，不要选择“以管理员身份运行”。无需安装 .NET、Python、Node 或编译工具。
2. 安装完成后会打开使用说明和 `extension` 文件夹。在 Edge 地址栏输入 `edge://extensions/`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择该文件夹。若找不到，在选择窗口的地址栏粘贴 `%LOCALAPPDATA%\TsinghuaAutoLoginShared\extension`。
3. 设置页首次检查连接成功时，会自动弹出明显的“连接成功”；手动点击“检查连接”成功时也会弹出。保存清华账号和密码；邮箱凭据不同时，再单独保存邮箱账号密码。保存后的后台检查不会反复弹出连接成功提示。
4. 打开网络学堂、信息门户或学生邮箱。出现验证码或二次验证时，由你继续完成。

本包尚未获得可信代码签名。如果 Windows 提示“智能应用控制已阻止此应用”“无法验证其发布者”，请先阅读下方“智能应用控制拦截”。这份提示不能靠重新解压或以管理员身份运行来解决。

安装文件只负责准备助手和扩展文件。加载扩展仍需在 Edge 中手动完成一次；安装程序不会关闭浏览器安全限制，也不会代替你开启开发人员模式。

## 智能应用控制拦截

### 为什么会拦截，签名能否解决

当前 `安装.exe`、`卸载.exe` 和安装后的本机助手均未获得可信代码签名。Windows 如果无法判断程序安全性，又找不到有效的可信签名，就可能阻止它运行。这是发布者信任检查，尚不能据此判断程序功能是否正常，也不能据此证明程序安全。智能应用控制目前没有“仅允许这一个应用”的例外按钮。[微软说明](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

较稳妥的长期方案是开发者申请受 Windows 信任的代码签名，并对助手、安装程序、卸载程序及其他需要的可执行组件完成签名与实测。自签名证书、文件属性里的发布者文字或 `SHA256SUMS.txt` 都不能代替这种签名。校验值只用于核对文件一致性。可信签名也不等于安全审计通过，SmartScreen 的信誉提示与学校管理策略仍可能独立生效。[微软签名要求](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/code-signing-for-smart-app-control)

当前项目没有可用的可信签名身份，尚不能提供已签名包。愿意等待的使用者可以保留应用控制开启，暂不安装。下面仅说明电脑所有者自行决定继续测试时的系统操作；程序不会自动更改该设置。

### 决定关闭之前

关闭智能应用控制会减少**整台电脑**对未知或不受信任程序的执行保护，不是只对本安装包放行。若这是学校或单位管理的电脑，应交由管理员处理；不要尝试绕过管理策略。

先安装 Windows 更新并查看设置页的提示。截至 2026-11-12，微软说明较新的 Windows 更新已支持关闭后重新开启，无需全新安装；较旧系统或特定设备状态仍可能限制恢复。如果本机提示关闭后需要重置或重装才能恢复，请按该提示判断，不能把此次操作视作可随时撤回。[当前常见问题](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

如果“开启”选项变灰，先检查更新。微软还记录了 2026 年 10 月更新造成部分设备无法重新开启的问题，并公布了后续更新中的修复；不要为了测试本助手直接重置电脑。[微软更新说明](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127648-windows-11-24h2-25h2-26h2-security-update)

### 关闭与恢复的方法

1. 在 Windows 开始菜单搜索并打开 **Windows 安全中心**。
2. 进入 **应用和浏览器控制 → 智能应用控制设置**。
3. 选择 **关闭**，阅读系统提示；只有在电脑所有者接受上述影响时才确认。若选项受组织管理或无法修改，停止并联系管理员。
4. 回到完整解压的安装包，直接双击 **安装.exe**，继续上面的首次安装步骤。无需选择“以管理员身份运行”。
5. 测试结束后，回到同一位置选择 **开启**（如果系统允许）。保持 Microsoft Defender 防病毒、实时保护、防火墙及其他保护开启，不要因仍有拦截而逐项关闭它们。[设置入口](https://support.microsoft.com/en-gb/windows/security/windows-security/app-browser-control-in-the-windows-security-app?nochrome=true)

**重新开启后，本机助手仍可能再次被拦截。** 助手每次由 Edge 按需启动，安装成功不会使未签名的助手自动获得信任。因此，这不是“仅安装时关闭、装完恢复后就保证一直可用”的方案。如果恢复保护后连接失败，请停止使用并反馈，等待可信签名版本。

## 日常使用

日常无需打开助手。左键工具栏图标在当前标签页手动重登；右键图标选择“扩展选项”可返回设置页。设置页的三个“打开网站”链接会新开标签页，并明确启动一次登录。即使自动模式关闭，主动点击这些链接也允许这一次登录；不会因此改变已保存的自动开关。总开关和三个网站开关控制无人操作时的自动模式。WEBVPN 属于“信息门户”，没有第四个开关。

0.1.7 修复了“首次提交到二次验证后，再从设置页打开其他网站不填写”的问题：普通链接曾受到前一次提交留下的等待时间影响，现在每次主动点击会建立独立的手动尝试。普通网页的自动重试保护保留；验证码、二次验证和账号错误仍会停止当前流程，不循环提交。

未单独保存邮箱凭据时，邮箱使用清华账号密码。主动编辑登录框时，自动流程暂停；遇到密码错误、验证码或二次验证时停止，不循环提交密码。

密码由 Windows 当前用户加密保存。密码框、眼睛图标和复制按钮都不会读取已保存密码。保存后密码输入框清空。

## 更新与卸载

更新：解压新包，运行新包中的 **安装.exe**，程序会识别原安装并覆盖更新；不需要先卸载。完成后，在 Edge 扩展管理页点击本扩展的“重新加载”，若之前关闭了扩展开关，再重新开启。更新保留已保存密码和自动登录开关。本包仍未获得可信代码签名，应用控制的处理见上文。

当 Windows 不允许移动整个旧目录时，0.1.9 会保留安装目录，改为逐文件更新；替换前保存旧文件，失败时恢复，意外中断后下次运行会先恢复。内容相同的文件不重复替换。此方式不关闭浏览器、不修改系统权限。如果某个具体文件仍被占用或无写入权限，安装仍会停止，并指出失败文件。

更新的是 `%LOCALAPPDATA%\TsinghuaAutoLoginShared\extension` 中的共享版。若扩展仍从其他解压目录加载，重新加载不会更新那个旧目录：在扩展管理页查看共享版的来源路径，按首次安装步骤选择这里的固定安装目录。不要先移除扩展，以免删除浏览器内的开关设置；原个人版也不会被本安装器替换。

### 提示“已恢复原来的安装和连接配置”时

这表示更新中途失败并已恢复原安装，不表示新版安装成功。0.1.7 及以前的 Windows 包无论什么原因，都可能追加“请关闭浏览器后重试”，因此**不能仅凭旧提示判断一定是浏览器占用**。

新版会显示“失败步骤”和“诊断代码”，请保留弹窗完整文字。例如 `IOException/80070020` 表示文件共享冲突；`IOException/80070005` 或 `UnauthorizedAccessException/80070005` 表示 Windows 拒绝访问，可能与权限、文件占用或管理策略有关。安装包校验失败也会分别说明。不要删除旧安装目录、凭据目录或 `.transaction` 恢复目录。

若暂时不能退出浏览器，可以先保存学校页面中未提交的内容，在 `edge://extensions/` 关闭共享版扩展开关，再运行 **安装.exe**。这不移除扩展、不删除账号密码，也不关闭其他工作标签页；但不能保证释放所有文件占用。成功后重新开启并重新加载扩展。

如果新提示确认文件占用且上述办法无效，等工作允许时保存内容、完全退出 Edge／Chrome后重试；关闭相关标签页不等于退出浏览器，Edge 的启动增强或后台模式也可能保留进程。最容易排除后台占用的方法是重启 Windows 后先不要打开浏览器，直接运行安装。程序不会自动结束浏览器进程。[微软后台运行说明](https://support.microsoft.com/en-gb/edge/get-help-with-startup-boost)

若仍失败，请反馈 **安装包版本、失败步骤、诊断代码、是否显示已恢复**。无需发送账号密码、Cookie 或完整认证网址。

卸载：如需删除密码，先在设置页点击对应账号的“删除已保存密码”；再运行本包中的 **卸载.exe**，最后在 Edge 中移除扩展。卸载默认保留凭据，重新安装后可恢复使用。请保留本包，便于卸载。

程序安装位置：`%LOCALAPPDATA%\TsinghuaAutoLoginShared`。加密凭据位置：`%LOCALAPPDATA%\TsinghuaAutoLoginShared.Credentials.v1`。详情见同目录 `PRIVACY.md`。

## 请协助确认

### 从旧版更新并复测本次修复

1. 下载并完整解压本次 Windows 包。关闭旧学校页面和旧设置页；若要保留其他工作页面，可先在 Edge 扩展管理页关闭共享版开关，再尝试更新。文件被占用时按上节处理。
2. 双击新包中的 **安装.exe**。看到“安装完成”后重新打开 Edge。如果仍被智能应用控制阻止，请先阅读上文，不要把未完成安装的旧版本当作新版测试。
3. 在 Edge 地址栏输入 `edge://extensions/`，找到“清华网站自动重登 · 共享试用版”，点击“重新加载”。若有原个人版，先关闭它，避免两个扩展同时处理登录。
4. 打开共享版的“扩展选项”，确认设置页底部写着 **扩展版本 0.1.9**、连接处显示 **助手版本 0.1.2**。首次连接检查成功后，应出现绿色“连接成功”提示，约 6 秒后消失，也可点 × 关闭。
5. 确认清华账号显示“已保存”，无须为了本次测试重新输入密码。普通点击“打开网络学堂”，观察是否自动填写并提交一次。到达二次验证即记为“自动提交成功”，不要把它记为已经进入主页；二次验证仍需本人完成。
6. 关闭刚刚打开的学校标签页，返回设置页，依次测试“打开信息门户”“打开学生邮箱”，最后再次测试“打开网络学堂”。每次都先关闭上一个学校标签页；**不用等待 10 分钟，也不用清除浏览器设置或反复保存密码**。
7. 如果希望核对手动与自动的区别，可暂时关闭“自动处理登录失效”，再主动点击一个“打开网站”链接。这一次仍应尝试登录，测试后将开关恢复到你希望的状态。此操作不会代替二次验证。

### 若仍没有自动填写

1. 先回设置页点击“检查连接”。若失败，记录显示的完整提示；若成功，继续下一步。不要反复提交真实密码。
2. 再确认页尾为 0.1.9、对应账号显示“已保存”，以及所有旧学校标签页都已关闭。只打开一个新测试页。
3. 记录失败阶段：没有新开网页、打开登录页但没填入、填入后没提交、还是已经到了二次验证。网页出现本扩展的错误卡片时，记录其文字。
4. 在 Edge 扩展管理页查看共享版是否出现“错误”按钮；若有，打开并记录最新错误文字。请不要发送密码、网页请求记录、Cookie 或完整认证链接；截图时遮住账号及其他个人信息。
5. 反馈 **Windows 版本、Edge 版本、扩展版本、连接结果、失败网站与失败阶段**。Edge 版本可在右上角“…”→“帮助和反馈”→“关于 Microsoft Edge”查看；Windows 版本可按 Win＋R，输入 `winver` 后按回车查看。

先确认安装后“检查连接”成功，再测试网站。反馈时只需说明成功或在哪一步失败，不要发送真实密码。
