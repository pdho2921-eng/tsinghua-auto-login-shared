# 清华网站自动重登 · Windows 试用版

本包面向 **Windows 11、Intel／AMD 64 位电脑、Microsoft Edge**。这是等待 Windows 实机验收的测试包；生成安装程序、通过模拟检查，不等于已经确认 Edge 兼容。

扩展版本 0.1.6，Windows 助手版本 0.1.0。两者版本号不同是正常的。

## 首次安装

1. 解压完整压缩包，双击 **安装.exe**。直接以当前 Windows 用户运行，不要选择“以管理员身份运行”。无需安装 .NET、Python、Node 或编译工具。
2. 安装完成后会打开使用说明和 `extension` 文件夹。在 Edge 地址栏输入 `edge://extensions/`，开启“开发人员模式”，点击“加载解压缩的扩展”，选择该文件夹。若找不到，在选择窗口的地址栏粘贴 `%LOCALAPPDATA%\TsinghuaAutoLoginShared\extension`。
3. 在自动打开的设置页点击“检查连接”，应看到明显的“连接成功”。保存清华账号和密码；邮箱凭据不同时，再单独保存邮箱账号密码。
4. 打开网络学堂、信息门户或学生邮箱。出现验证码或二次验证时，由你继续完成。

本包尚未获得可信代码签名。如果 Windows 提示“智能应用控制已阻止此应用”“无法验证其发布者”，请先阅读下方“智能应用控制拦截”。这份提示不能靠重新解压或以管理员身份运行来解决。

安装文件只负责准备助手和扩展文件。加载扩展仍需在 Edge 中手动完成一次；安装程序不会关闭浏览器安全限制，也不会代替你开启开发人员模式。

## 智能应用控制拦截

### 为什么会拦截，签名能否解决

当前 `安装.exe`、`卸载.exe` 和安装后的本机助手均未获得可信代码签名。Windows 如果无法判断程序安全性，又找不到有效的可信签名，就可能阻止它运行。这是发布者信任检查，尚不能据此判断程序功能是否正常，也不能据此证明程序安全。智能应用控制目前没有“仅允许这一个应用”的例外按钮。[微软说明](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

较稳妥的长期方案是开发者申请受 Windows 信任的代码签名，并对助手、安装程序、卸载程序及其他需要的可执行组件完成签名与实测。自签名证书、文件属性里的发布者文字或 `SHA256SUMS.txt` 都不能代替这种签名。校验值只用于核对文件一致性。可信签名也不等于安全审计通过，SmartScreen 的信誉提示与学校管理策略仍可能独立生效。[微软签名要求](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/code-signing-for-smart-app-control)

当前项目没有可用的可信签名身份，尚不能提供已签名包。愿意等待的使用者可以保留应用控制开启，暂不安装。下面仅说明电脑所有者自行决定继续测试时的系统操作；程序不会自动更改该设置。

### 决定关闭之前

关闭智能应用控制会减少**整台电脑**对未知或不受信任程序的执行保护，不是只对本安装包放行。若这是学校或单位管理的电脑，应交由管理员处理；不要尝试绕过管理策略。

先安装 Windows 更新并查看设置页的提示。截至 2026-11-12，微软说明较新的 Windows 更新已支持关闭后重新开启，无需全新安装；较旧系统或特定设备状态仍可能限制恢复。如果本机提示关闭后需要重置或重装才能恢复，请按该提示判断，不能把此次操作视作可随时撤回。[当前常见问题](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

如果“开启”选项变灰，先检查更新。微软还记录了 2026 年 10 月更新造成部分设备无法重新开启的问题，并公布了后续更新中的修复；不要为了测试本助手直接重置电脑。[微软更新说明](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127648-windows-11-24h2-25h2-26h2-security-update)

### 关闭与恢复的方法

1. 在 Windows 开始菜单搜索并打开 **Windows 安全中心**。
2. 进入 **应用和浏览器控制 → 智能应用控制设置**。
3. 选择 **关闭**，阅读系统提示；只有在电脑所有者接受上述影响时才确认。若选项受组织管理或无法修改，停止并联系管理员。
4. 回到完整解压的安装包，直接双击 **安装.exe**，继续上面的首次安装步骤。无需选择“以管理员身份运行”。
5. 测试结束后，回到同一位置选择 **开启**（如果系统允许）。保持 Microsoft Defender 防病毒、实时保护、防火墙及其他保护开启，不要因仍有拦截而逐项关闭它们。[设置入口](https://support.microsoft.com/en-gb/windows/security/windows-security/app-browser-control-in-the-windows-security-app?nochrome=true)

**重新开启后，本机助手仍可能再次被拦截。** 助手每次由 Edge 按需启动，安装成功不会使未签名的助手自动获得信任。因此，这不是“仅安装时关闭、装完恢复后就保证一直可用”的方案。如果恢复保护后连接失败，请停止使用并反馈，等待可信签名版本。

## 日常使用

日常无需打开助手。左键工具栏图标在当前标签页手动重登；右键图标选择“扩展选项”可返回设置页。总开关和三个网站开关控制自动模式。WEBVPN 属于“信息门户”，没有第四个开关。

未单独保存邮箱凭据时，邮箱使用清华账号密码。主动编辑登录框时，自动流程暂停；遇到密码错误、验证码或二次验证时停止，不循环提交密码。

密码由 Windows 当前用户加密保存。密码框、眼睛图标和复制按钮都不会读取已保存密码。保存后密码输入框清空。

## 更新与卸载

更新：解压新包，关闭正在使用本扩展的浏览器窗口，再运行新包中的 **安装.exe**。完成后，在 Edge 扩展管理页点击本扩展的“重新加载”。更新保留已保存密码和自动登录开关。

卸载：如需删除密码，先在设置页点击对应账号的“删除已保存密码”；再运行本包中的 **卸载.exe**，最后在 Edge 中移除扩展。卸载默认保留凭据，重新安装后可恢复使用。请保留本包，便于卸载。

程序安装位置：`%LOCALAPPDATA%\TsinghuaAutoLoginShared`。加密凭据位置：`%LOCALAPPDATA%\TsinghuaAutoLoginShared.Credentials.v1`。详情见同目录 `PRIVACY.md`。

## 请协助确认

先确认安装后“检查连接”成功，再测试网站。反馈时只需说明成功或在哪一步失败，不要发送真实密码。

| 检查 | 预期结果 |
| --- | --- |
| 首次安装与加载 | 安装成功；Edge 出现设置页；点击检查连接显示“连接成功” |
| 保存与重开 | 密码框清空；关闭并重开 Edge 后仍显示已保存 |
| 三个网站 | 分别能自动提交；停在二次验证也算提交成功，但不算已进入主页 |
| 邮箱回退 | 未单独保存邮箱时使用清华凭据；删除独立邮箱凭据后恢复回退 |
| 手动编辑、错误与验证码 | 停止自动处理，不重复提交 |
| 开关与工具栏 | 关闭网站自动模式后不自动处理；点击图标仍可手动重登；设置页点击图标不跳转 |
| 重复安装、卸载、重装 | 不出现半安装；密码与开关按上述规则保留 |
