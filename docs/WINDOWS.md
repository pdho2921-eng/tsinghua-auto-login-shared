# 清华网站自动重登 · Windows 试用版

本安装包供 Windows 11、Intel／AMD 64 位电脑使用，已在 Windows 11 + Edge 上做过简单测试。Windows 10 及以下版本、Windows Chrome 仍待实测反馈。

发布整理版 **v0.1.9-preview.1**。扩展版本 **0.1.9**，Windows 助手版本 **0.1.2**。

## 首次安装

1. 解压完整压缩包，双击 `安装.exe`。使用当前 Windows 账号直接运行，无需选择“以管理员身份运行”。
2. 安装完成后，按自动打开的“开始使用”说明，在 Edge 地址栏输入 `edge://extensions/` 或手动打开扩展管理，开启“开发人员模式”，点击“加载解压缩的扩展”，选择安装后打开的 `extension` 文件夹。
3. 设置页首次检查连接成功时自动显示“连接成功”，也可以手动点击“检查连接”运行检查，出现问题时打开下方折叠的“尚未安装或连接失败”排查。保存清华账号和邮箱的账号密码，可省略邮箱凭据填写并使用清华账号密码登录邮箱。

扩展位置为 `%LOCALAPPDATA%\TsinghuaAutoLoginShared\extension`，可以在“加载解压缩的扩展”的文件选择窗口地址栏粘贴路径。

这是尚未获得可信代码签名及上架的试用包。如果 Windows 提示“智能应用控制已阻止此应用”或“无法验证其发布者”，请按下节说明处理。安装流程不会关闭系统安全检查。

### 智能应用控制拦截

当前安装程序、卸载程序和本机助手均未获得可信代码签名，可能被智能应用控制拦截。自签名证书和文件校验值不能代替可信签名；项目目前没有可用的签名身份，后续需要为相关程序完成签名与实测。[微软签名说明](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/code-signing-for-smart-app-control)

智能应用控制没有单独放行本插件的选项。关闭它会减少**整台电脑**对不受信任程序的执行保护，可以选择保持开启、暂不安装。学校或单位管理的电脑请联系管理员处理。[微软常见问题](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

如果决定关闭后继续试用：

1. 在开始菜单搜索并打开 **Windows 安全中心**，进入 **应用和浏览器控制 → 智能应用控制设置**。
2. 选择 **关闭**，阅读并确认系统提示。如果选项受组织管理，请联系管理员。
3. 回到完整解压的安装包，双击 `安装.exe`，继续首次安装步骤。保持防病毒、实时保护和防火墙开启。
4. 如需恢复，回到同一位置选择 **开启**。微软说明近期 Windows 更新已支持重新开启；旧系统或部分设备仍可能受限，操作前应检查更新并以本机提示为准。如果提示需要重置或重装才能恢复，请先考虑能否接受。[恢复说明](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

重新开启后，未签名的本机助手仍可能被拦截，安装成功不代表之后一定能运行。如果恢复保护后连接失败，请反馈并等待可信签名版本。

## 日常使用

助手由浏览器按需启动，无需手动打开。支持网络学堂、信息门户（含 WEBVPN）和学生邮箱。插件适用范围由页面最下方的总开关与三个网站开关控制，默认均开启，可自行选择打开哪些网站的自动重连。日常使用时，在支持网站中左键工具栏图标在当前标签页手动激活重登，右键图标选择“扩展选项”可返回设置页。

设置页的三个“打开网站”链接会新开标签页并启动一次登录，即使自动模式关闭，也允许这一次主动操作。系统要求二次验证后停止，不会循环提交。

主动编辑登录框时会暂停自动处理，遇到密码错误、验证码或额外验证时停止，并在右下角弹窗说明。

密码由 Windows 加密保存在这台电脑，登录当前 Windows 账号后可自动使用。

## 更新与卸载

更新时解压新包，运行其中的 `安装.exe`。程序可以识别已有安装并覆盖更新，无需先卸载。随后在 Edge 扩展管理页重新加载扩展，刷新原先打开的学校网站即可启用新版。新版安装失败时会尝试恢复旧安装，恢复未完成时会提示备份路径。更新保留密码和自动登录开关。

若旧安装目录不能整体移动，程序会尝试逐文件更新；具体文件仍被占用或无写入权限时，会停止并显示失败步骤和诊断代码。如浏览器之前从其他解压目录加载扩展，请重新选择上方固定安装目录，不要先移除扩展，以免删除已保存的开关设置。

如需卸载，先打开设置页，点击对应账号的“删除已保存密码”删除保存的密码。然后运行安装包内置的 `卸载.exe`，最后在浏览器中移除扩展。只运行卸载会继续保留加密凭据，重新安装后可使用原 Windows 账号读取。

本项目没有账号服务器或遥测，详情见 `PRIVACY.md`。

### 安装或更新失败

提示“已恢复原来的安装和连接配置”表示安装中途失败，原安装已恢复，新版尚未安装成功。请保留完整提示，不要删除安装目录、凭据目录或 `.transaction` 恢复目录。

1. 保存网页中未提交的内容，在 Edge 扩展管理页暂时关闭本扩展开关，再运行 `安装.exe`。安装成功后重新开启并重新加载扩展，刷新学校网站。
2. 如果提示文件占用且仍失败，等工作允许时完全退出 Edge／Chrome 后重试；只关闭相关标签页不一定能释放占用，也可以重启 Windows 后先不打开浏览器，直接运行安装程序。访问被拒绝也可能由权限或管理策略引起，关闭浏览器不能解决所有情况。
3. 若仍失败，请反馈 Windows 版本、浏览器版本、安装包版本，以及弹窗中的失败步骤、诊断代码和是否已恢复。截图时遮住账号，不要发送密码、Cookie 或完整认证链接。

如果安装成功但没有自动填写，先在设置页检查连接及账号保存状态，再记录失败网站、页面提示，以及是“未填写”“未提交”还是“已到二次验证”。到达二次验证表示自动提交已完成，后续验证仍需本人操作。
